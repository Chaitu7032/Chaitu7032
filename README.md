### 🏗️ Current Architecture Focus

Currently exploring incremental improvements to the Music Blocks block architecture.

The approach focuses on gradually moving block behavior ownership toward block definitions and `ProtoBlock` metadata while preserving existing runtime behavior.

```text
Legacy Behavior
      │
      ▼
Capability Metadata
      │
      ▼
Runtime Accessors
      │
      ▼
Behavior-Preserving Migration
      │
      ▼
Smaller & More Maintainable blocks.js
```

> **Engineering principle:** Large legacy systems are improved through small, reviewable, test-backed changes — not risky rewrites.
